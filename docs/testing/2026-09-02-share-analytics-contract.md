# 分享数据只读契约验收（2026-09-02）

## 结论

已使用当前用户授权、由应用加密保存的百度会话完成真实只读验收。硬门槛通过：接口可完整分页读取“我的分享”，并在每条记录中提供稳定身份、名称或路径、分享链接、创建时间、状态，以及转存、浏览、下载三项非负历史累计值。

验收覆盖了一个具有大量历史分享记录的真实账号。所有页均成功读取，跨页分享身份没有重复。本文不记录账号标识、Cookie、分享标识、标题、链接、查询令牌、原始响应或真实记录总数。

## 冻结的请求契约

- 方法：`GET`
- 主机：`pan.baidu.com`
- 端口：HTTPS 默认端口
- 路径：`/share/record`
- 请求体：禁止
- 自动重定向：禁止
- 查询键：`page`、`desc`、`order`
- `page`：十进制正整数
- `desc`：固定为 `1`
- `order`：固定为 `time`
- 单页响应上限：1 MiB
- 分页硬上限：10,000 页

任何其他方法、主机、端口、路径、查询键、非正页码、溢出页码、请求体、重复 URI 或越界分页都会在发送前被拒绝。

## 分页语义

- `list` 是当前页记录数组。
- `count` 是当前页条数，不是账号总数。
- 当前契约的满页为 100 条。
- `nextpage` 是是否仍有后续页的数值标志，不是下一页页码。
- 满页且 `nextpage` 为正数时，请求 `page + 1`。
- 返回不足 100 条时分页结束；末页恰好满 100 条时，下一空页作为确定性终止页。
- 验收同时检查跨页分享身份唯一性，防止服务端忽略页码后反复返回同一页。

## 成功响应字段

根对象：

- `errno`: number，成功时为零
- `list`: array
- `count`: number
- `nextpage`: number
- `request_id`: number

每条分享记录所需字段：

- `shareId`: number，稳定分享身份
- `typicalPath` 或 `name`: string，显示名称或路径
- `shortlink` 或 `shorturl`: string，分享链接
- `ctime`: number，创建时间
- `status`: number，当前状态
- `tCnt`: number，历史转存累计
- `vCnt`: number，历史浏览累计
- `dCnt`: number，历史下载累计

三项累计值在真实验收的所有记录中均为非负整数。其他观察到的字段不属于首版功能依赖，不冻结为正式契约。

## 失败与日志约束

- HTTP 非成功状态、非 JSON、响应超限或缺少身份字段：整次同步失败，不提交半页或半批数据。
- 单个统计字段缺失或类型异常：正式适配器将该项映射为缺失值，界面显示 `--`；身份、链接、时间或状态损坏则拒绝该页。
- 只读瞬时请求失败：重试一次；仍失败则标记本次刷新失败并保留上次完整缓存。
- 会话失效：提示重新扫码，不回退到浏览器 DOM 自动化。
- 日志只允许输出路由名、方法、状态码、页数、条数、JSON 字段路径与值类型；所有响应值、游标、Cookie、账号和分享内容必须脱敏。
