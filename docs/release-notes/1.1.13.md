# v1.1.13 · 2026-10-15

- 知道采集支持导入多个知道账号（TXT 或整段粘贴），本机加密保存；勾选的账号全部直连、轮换采集
- 知道采集新增暂停/继续，暂停后关掉软件再打开也能接着采
- 采集结果右键可打开链接（自动带提取码）和检测链接是否有效，结果表显示链接状态
- 转存待处理列表新增上一页、右键删除（可多选）和「只看冲突」
- 转存新增暂停/继续和停止；转存中关闭软件会先提醒，停止后的批次可以清空
- 修复转存一直「等待」：分享结果长时间核对不到时自动收尾，不再卡住后面的批次
- 转存出错时运行日志直接写出第几条、什么原因；之前的失败不再让后面每行进度都标红
- 修复链接列带超链接的 Excel（例如 WPS 保存的表格）导入时提示「包含异常内容」
- 软件自动把运行情况写入「运行日志.txt」，出问题时可以直接发来排查
