# v1.1.14 · 2026-10-17

- 运行日志改为保存在软件所在文件夹的 logs 里，打开软件目录就能找到；写不进去时会提醒并让你选择保存位置
- 转存批次卡在失效账号上收不了尾时，会说明在等哪个账号，并提供「放弃收尾」；长时间没有进展会自动放弃收尾，不再挡住后面的批次
- 放弃收尾时未确认的记录记为失败（结果未确认），这些可能其实已经转存或分享成功，请到网盘核对
- 添加账号时登录窗口空白：分开提示没装网页组件、组件启动失败、网页打不开等原因；没装组件时提供下载按钮，软件打开时也会提醒
- 修复退出账号后再登录同一个百度账号，提示「已经添加」无法登录
- 监控反馈「刷新数据」显示刷新进度和结果，请求无响应时不再一直卡住
- 修复分享较多的账号监控反馈一直刷新失败、数据停在旧日期的问题
