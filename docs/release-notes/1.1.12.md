# v1.1.12 · 2026-09-30

- 知道采集支持精准每词一条、模糊按目标总条数采集，采集进度与运行日志实时显示
- 关键词可直接导入 Excel（.xlsx）、CSV、TSV、TXT，自动识别关键词列、去重追加，每批最多 10000 个
- 模糊采集优先搜索最近一个月，三轮后最多扩大到近三个月；日期不明或超期的结果不收入
- 多个关键词先尝试各采一条，再补足目标总数；预算内未找到合格资源的关键词会在日志中说明
- 同一任务复用正常搜索页和详情页，减少重复请求；达到目标后及时结束辅助搜索
- 采集结果支持复制链接、导出 Excel、送入批量转存，以及右键全选、反选和取消选择
- 修复采集停止与异常提示、中文乱码、链接提取码边界和转存编辑区跟随选中行的问题
- 首页功能介绍同步当前导航，补充知道采集与设置中心；清理未使用代码并保留原有界面布局
