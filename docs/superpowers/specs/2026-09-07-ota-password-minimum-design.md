# OTA 管理员密码最低长度调整

## 目标

把 OTA 发布后台的新管理员密码最低长度从 16 位调整为 8 位。用户自行决定密码内容。

## 设计

- 最低长度统一按 Unicode 码点计数；后端和网页均接受至少 8 位，少于 8 位继续拒绝。最大长度仍按 UTF-8 字节计数且保持 1024 字节不变。
- 首次强制改密与以后主动改密沿用同一新密码规则。
- 网页新密码输入框显示“至少 8 位”，并使用与后端一致的 Unicode 码点计数校验；不依赖含义不同的 HTML 原生 `minlength`。
- 初始一次性密码的生成长度不变。
- 只调整新密码最低长度常量、计数规则及对应界面。Argon2id 参数、登录和当前密码验证、回滚密码确认、1024 字节上限、不裁剪/不规范化、复杂度规则、登录限流、会话、CSRF、首次强制改密和初始密码生成等其他行为不变。

## 验收

- 首次强制改密和以后主动改密都满足：7 位新密码被拒绝，8 位新密码被接受，并能使用新密码重新登录。
- 使用非 ASCII 向量验证前后端一致，例如 7 位 `密码密码密码a` 被拒绝，8 位 `密码密码密码ab` 被接受。
- 1024 字节仍被接受，1025 字节仍被拒绝。
- 网页校验和说明均显示最低 8 位。
- OTA 后台完整 Go 测试和重新构建通过。
- 生产部署作为代码验证后的独立执行步骤；部署时使用现有隔离安装流程，部署后真实网页显示新规则，原有站点及 OTA 静态资源不受影响。
