# 多软件卡密授权系统设计

## 目标

为 SuperPan 及后续 Windows 桌面软件提供一套自建、轻量、统一的卡密授权系统。管理员在现有 `ota.fanfh.cn` 管理后台中维护软件、套餐、卡密和机器绑定；客户端以同一张卡在同一台电脑上使用套餐允许的多款软件。

本期优先保证简单、易用、低服务器负载和与现有 OTA/其他网站隔离，不建设支付、代理商或客户账户体系。

## 已确认规则

- 卡种固定为月卡 30 天、季卡 90 天、半年卡 180 天、年卡 365 天。
- 卡密首次成功激活时开始计时，所有到期判断使用服务器时间。
- 管理员可以创建多款软件；软件拥有永久不变的内部 ID，改名不影响授权。
- 软件只能停用，不能删除。停用某软件只拒绝该软件的新验证，不影响套餐内其他软件。
- 管理员创建套餐时可以选择一款、多款或全部软件。
- 卡密绑定套餐而不是绑定单一软件。套餐成员动态生效：新增软件后，已有卡密立即获得授权；移除软件后，已有卡密立即失去授权。
- 一张卡密绑定一台电脑。同一台电脑只需激活一次，同一张卡授权的其他软件自动识别。
- 更换电脑或重装导致机器指纹变化时，只能由管理员手动解绑；用户不能自行解绑。
- 管理员续费直接延长原卡密到期时间，不换卡。延长基准为服务器时间与当前到期时间的较晚者。
- 删除卡密是永久删除：活动数据库中同时删除卡密、机器绑定和有效验证租约，不提供回收站或恢复按钮。
- 软件启动和执行远端核心操作前验证，不进行固定周期轮询。
- 服务器临时不可连接时，最近一次成功验证结果最多宽限 30 分钟；首次激活没有离线宽限。
- 已开始的批次不因卡密随后到期、删除或断网而强行中止；继续、重试或开始新任务前必须重新验证。
- 不显示到期前提醒。

## 总体架构

### 统一后台与内部隔离

管理员继续访问 `https://ota.fanfh.cn/admin/`，使用现有管理员登录。后台新增：

1. 软件管理
2. 套餐管理
3. 卡密管理
4. 设备绑定

卡密运行时使用独立的 `superpan-license` 服务、独立 loopback 端口和独立 SQLite 数据库。Nginx 只把公开验证接口代理到该服务；服务不访问 OTA 发布目录和其他网站目录。

管理浏览器仍只与现有 OTA 管理服务通信。OTA 管理服务使用仅限 loopback 的内部凭据调用卡密服务的管理接口，因此管理员只登录一次，卡密服务的管理接口不直接暴露公网。

公开客户端接口使用同源路径：

- `POST /license-api/v1/activate`
- `POST /license-api/v1/validate`

服务端健康检查仅允许本机或受控验证脚本访问。OTA 静态下载不依赖卡密服务；卡密服务停止时，OTA 稳定通道仍可正常下载。

### 客户端集成

每款软件构建时嵌入自己的不可变软件 ID 和卡密服务公开验证配置。客户端共用一个本机授权存储，卡密用 Windows DPAPI 加密，不以明文写入配置、数据库或日志。

共享存储可以保存多张卡。每款软件启动时选择一张当前允许该软件的卡进行验证；同一张卡在第一款软件成功激活后，其他被套餐授权的软件无需再次输入。

客户端只提交卡密、软件 ID、机器指纹哈希、请求随机数和必要的协议版本。原始硬件字段不上传。

## 数据模型

### 软件

- 不可变软件 ID
- 显示名称
- 启用/停用状态
- 创建时间、更新时间

### 套餐

- 不可变套餐 ID
- 套餐名称
- 当前包含的软件 ID 集合
- 创建时间、更新时间

套餐成员是动态关系，变更后对所有引用该套餐的现有卡密立即生效。

### 卡密

- 不可变卡密 ID
- 所属套餐 ID
- 卡种与授权天数：30/90/180/365
- 未激活/有效/已到期状态（删除后记录不存在）
- 首次激活时间、到期时间
- 后台备注
- 生成批次与创建时间
- 绑定机器指纹哈希

完整卡密在服务器中使用独立 root-only 密钥加密存储，用于后台复制与导出；检索和验证使用独立的带密钥摘要索引。列表默认遮挡卡密，仅在管理员明确复制或导出时解密。后台备注不下发客户端。

### 验证租约

客户端保存服务器签发的短期验证结果，包含卡密 ID、机器哈希、软件 ID、签发时间和最迟宽限时间。租约最长 30 分钟，仅用于服务器暂时不可连接时的宽限，不能延长卡密本身到期时间。

## 业务流程

### 生成与分发

1. 管理员创建软件。
2. 管理员创建套餐并选择一款、多款或全部当前软件。
3. 管理员选择套餐、卡种、生成数量和可选默认备注。
4. 后台批量生成卡密，支持复制和表格导出。
5. 管理员可以逐张修改备注，并按卡密、备注、套餐、卡种和状态搜索筛选。

### 首次激活

1. 未找到适用本机授权时，客户端显示精简激活窗口。
2. 用户输入卡密，客户端计算稳定机器指纹哈希并请求激活。
3. 服务端确认卡密存在、尚未绑定或已绑定同一机器、套餐包含当前软件且软件已启用。
4. 未激活卡从服务器当前时间开始计算固定天数并绑定机器。
5. 客户端加密保存卡密和验证结果后进入软件。

### 日常验证

- 软件启动时验证一次。
- 开始转存、分享、刷新远端数据等核心远端操作前验证。
- 软件闲置时不请求服务器。
- 同一批次执行期间不重复验证，也不因授权状态变化强制中断。
- 服务器明确返回卡密不存在、已到期、机器不匹配、软件停用或套餐无权时，不得使用缓存继续操作。
- 只有连接失败、超时或服务器 5xx 才允许使用仍在 30 分钟范围内的上次成功结果。
- 宽限过期后禁止开始新任务，但允许打开软件查看本地数据和进入设置中心。

### 续费、解绑与删除

- 续费把到期时间延长相应固定天数；未激活卡则增加首次激活后可获得的总天数。
- 解绑清除机器绑定和现有租约，不改变剩余有效时间；下一台电脑激活时继续使用原到期时间。
- 永久删除在单个事务中删除卡密、绑定和租约。之后所有在线验证立即返回卡密无效；已启动批次可完成，后续操作被拒绝。

## 后台界面

### 软件管理

显示软件名称、内部 ID、状态和套餐数量。允许新增、改名、停用和重新启用，不提供删除。

### 套餐管理

显示套餐名称和已选软件。管理员使用复选列表调整成员；保存后立即影响现有卡密。执行移除操作前明确显示会受影响的有效卡密数量。

### 卡密管理

顶部提供套餐、卡种、数量和默认备注，支持批量生成。列表包含卡密遮挡值、套餐、卡种、状态、激活时间、到期时间、绑定状态和备注，并支持：

- 搜索与筛选
- 复制单张卡密
- 批量导出
- 修改备注
- 续费
- 解绑机器
- 永久删除

永久删除需要二次确认，并明确显示“删除后无法恢复”。

### 设备绑定

按卡密查看机器指纹的短标识、绑定时间和最后成功验证时间。只提供管理员解绑，不显示或存储原始硬件信息。

## 客户端界面

未激活窗口只包含产品名称、卡密输入框、激活按钮、状态提示和关闭按钮。设置中心显示套餐、到期时间、授权状态和机器绑定状态，不显示续费入口或到期前提醒。

卡密无效时使用统一中文原因：

- 卡密无效
- 卡密已到期
- 该卡密未授权当前软件
- 当前软件已停用
- 卡密已绑定其他电脑，请联系管理员解绑
- 无法连接授权服务器，请检查网络后重试

客户端日志不得记录完整卡密、机器指纹、验证租约或后台内部错误。

## 安全与容量控制

- 所有公网请求必须使用 HTTPS，客户端固定授权服务的受信公钥或 SPKI。
- 验证结果由独立授权签名密钥签名，客户端内置对应公钥；不得复用 OTA 发布私钥。
- 激活和验证请求包含随机数与时间窗口，服务端拒绝明显重放。
- 卡密生成使用密码学安全随机数，显示格式便于人工复制但保留足够熵。
- 管理、激活和验证接口分别限流；失败采用指数退避并加入随机错峰。
- 普通验证不在每次请求同步写 `last_seen`；最后在线时间异步合并，最多每卡每小时写一次，避免 SQLite 写锁成为瓶颈。
- 卡密、套餐成员和软件状态使用索引查询；服务进程设置自动重启、超时、日志轮转和健康检查。
- 上线前完成 50 与 100 请求/秒、各 10 分钟的真实接口压力测试，观察错误率、p95 延迟、CPU、内存和数据库锁。
- 卡密服务使用独立数据库、数据目录、系统用户和 systemd unit；部署/回滚不得改写现有 OTA 发布树或其他站点。
- 在卡密正式上线前完成 SSH 密钥登录、限制 root 密码登录和防扫描措施；不得在未验证密钥登录可用前关闭现有登录路径。

## 错误处理

- 明确业务拒绝不得降级为离线宽限。
- 网络失败只在本机存在未过期的成功租约时宽限，且界面显示当前使用临时授权。
- 激活请求重试必须幂等，同一卡密与同一机器重复激活返回相同授权状态。
- 套餐变更、续费、解绑和删除使用数据库事务；失败时不得留下部分状态。
- 客户端机器指纹读取失败时不得生成随机新指纹，应提示无法取得设备标识。

## 测试与验收

### 服务端

- 四种固定授权天数和服务器时间边界。
- 首次激活幂等、机器冲突、解绑后重绑。
- 套餐新增/移除软件对已有卡密立即生效。
- 软件停用只影响该软件。
- 续费基准、未激活续费和到期续费。
- 永久删除级联删除且随后验证无效。
- 管理接口认证、卡密加密、日志脱敏、限流与重放拒绝。

### 客户端

- 首次激活与同机多软件自动复用。
- 启动和每个核心操作前验证，闲置时零轮询。
- 明确拒绝不使用缓存；网络故障仅在 30 分钟内宽限。
- 运行中批次不强停，继续/重试/新任务重新验证。
- DPAPI 存储、卡密和机器信息不进入日志。

### 部署

- 卡密服务停止、重启和回滚不影响 OTA 稳定文件下载。
- Nginx 只暴露预定公开路径，内部管理端口保持 loopback。
- 部署前后复核现有 OTA 健康页、稳定版本、证书和其他站点基线。
- 真实客户端完成激活、跨软件复用、套餐动态变更、续费、解绑、删除和网络宽限验收。
- 真实接口完成 50/100 请求每秒压力测试后再开放生产使用。

## 明确不做

- 在线支付、自动售卡和订单系统
- 代理商、子管理员和客户账户
- 用户自助解绑
- 永久卡、试用卡、次数卡和并发席位授权
- 固定周期心跳或在线人数强制控制
- 离线激活文件
- 到期前弹窗提醒
- 卡密回收站
- 强制中断已经开始的批次
