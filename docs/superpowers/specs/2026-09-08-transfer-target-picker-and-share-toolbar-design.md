# 转存目录选择与分享数据工具栏设计

## 目标

按用户确认的预览调整两个工作区：批量转存顶部保持清晰、紧凑且可直接选择百度网盘目标目录；分享数据把重复的两层卡片合并成一块两行工具栏。

## 批量转存

- 保留现有自适应批量粘贴框，支持 2–8 行高度并随内容增长。
- 修复全局 `ComboBox` 模板：选择内容与右侧下拉箭头使用独立列，窄控件中数字不得被遮挡。
- “目标目录”不再允许手工输入。改为显示当前路径的按钮，点击后打开软件内的百度网盘目录选择窗口。
- 目录窗口通过当前登录账号的只读网盘目录接口逐级加载文件夹；支持进入子目录、返回上一级、取消和“选择此目录”。
- 单账号模式使用所选账号浏览；多账号模式以第一个所选账号作为目录浏览来源，并把最终路径统一应用到所有参与账号。确认后同时更新工具栏的 `Wizard.DefaultTargetPath` 和每个已选账号的路径，不改动未选账号已有的路径。实际转存时，其他账号若不存在该路径，沿用现有目标目录准备逻辑。
- 本机“结果目录”仍使用原有本地文件夹选择方式。

## 分享数据

- 删除页面内部重复的“分享数据”标题和第一层独立信息卡。
- 合并为一个两行工具栏：
  - 第一行：账号与缓存时间、转存/浏览/下载指标、全部/有效/失效数量、刷新数据。
  - 第二行：标题搜索、状态筛选、已选数量、序号范围、选取/全选/反选/清空、导出表格。
- 去掉占空间的排序说明，表头本身继续支持点击排序，缺失数据仍排在最后。
- 标题搜索只处理本地缓存：输入停顿 300 毫秒后筛选，按回车立即筛选，清空后恢复全部结果。
- 数据表紧贴工具栏并继续保留水平滚动条、虚拟化、排序高亮和批量选择。

## 错误处理

- 未选择账号时不打开目录窗口，并以中文状态提示用户先选账号。
- 登录会话缺失或目录读取失败时，在目录窗口中显示简短中文错误；不修改原目标路径。
- 用户取消目录选择时保持现有路径不变。
- 会话读取必须使用本地账号 ID 的规范 `D` 格式字符串作为存储键。
- 快速连续进入目录时取消上一次读取，并用请求代次防止过期结果覆盖当前目录；读取期间禁用导航，根目录禁用“上一级”，关闭窗口取消未完成读取。
- 搜索延迟在视图层实现，不发起网络请求，也不改变缓存刷新计时。

## 验证

- 自动化测试覆盖下拉箭头与内容分列、目录导航/选择/取消/错误及异步竞态、目标路径应用范围、粘贴框保留、分享数据单工具栏结构，以及搜索延迟、回车立即提交和清空恢复全部结果的真实行为。
