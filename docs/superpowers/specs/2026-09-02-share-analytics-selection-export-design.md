# 分享数据表格重排、批量选择与导出设计

## 目标

修复分享数据表格的表头对齐和标题显示问题，删除“分享时间”列，按用户指定的顺序重排字段，并为十万级分享记录增加稳定的批量选择、序号区间选取和 Excel 导出能力。

本轮保持分享数据工作区只读。导出仅写入用户选择的本机目录，不修改百度网盘分享记录或 SQLite 分享缓存。

## 表格布局

最终列顺序固定为：

`复选框｜序号｜历史累计｜新增｜今天｜昨天｜前第 2 天｜前第 3 天｜前第 4 天｜链接｜标题｜状态`

- 删除“分享时间”显示列，但缓存记录仍可保留分享时间作为稳定排序的内部依据。
- 所有表头使用统一高度、垂直居中和水平居中；标题数据单元格左对齐，数值数据单元格右对齐。
- 标题和状态移动到最右侧。标题列提供足够宽度并使用文本截断提示。
- 数据表宽度允许超过可视区域，底部横向滚动条始终可用，用户可拖到右侧查看标题和状态。
- 保留当前排序列的表头箭头和整列淡黄色高亮；取消分享时间列后，默认排序仍可内部使用分享时间降序，但不显示该列。

## 标题修复

当前生产数据中标题显示为 `0`，原因是读取远端分享记录时优先采用了占位字段。

- 远端契约只接受字符串字段 `typicalPath` 和 `name`。先读取 `typicalPath`，再读取 `name`。
- `typicalPath` 先去除首尾空白和尾部 `/`、`\`，再同时按 `/`、`\` 分隔并取最后一个非空段；字段为数组、对象、数字或其他类型时视为无效。
- 两个字段的候选值都必须先去除首尾空白；去除后精确等于 `0` 的值视为占位，不得作为标题写入新缓存。合法的其他纯数字标题仍然允许。
- 两个字段都无有效名称时，使用稳定的分享标识作为安全兜底，不显示 `0`。
- 已经写入 SQLite 的 `0` 无法离线还原；页面加载旧缓存时立即用分享标识替代显示，下次手动刷新或 23 小时自动同步后写入真实标题。
- 标题解析失败不得导致整页统计数据丢失，除非分享记录的稳定身份、链接或时间等安全关键字段本身无效。

## 选择工具栏

筛选区增加一行选择工具栏：

`已选 N 条 / 共 M 条｜从 [起始序号] 到 [结束序号]｜选取｜全选｜反选｜清空选择｜导出表格`

- 序号以当前筛选、当前指标和当前排序后的结果全集为准，从 1 连续编号。“结果全集”包括虚拟化后尚未实例化、当前屏幕外和滚动区域外的所有匹配记录，不是 DataGrid 当前显示的可视行。
- 区间为闭区间。例如 `1` 到 `50` 选择当前结果的第 1～50 条。
- 区间选取只增加选中记录，不清除区间外已有选择。
- 起始或结束为空、不是正整数、起始大于结束或完全超出当前结果时，不改变选择并显示稳定中文提示。
- 结束序号超过当前结果时截断到最后一条。
- “全选”“反选”“清空选择”只作用于当前筛选结果；隐藏记录的选择状态不受影响。
- 选择身份使用 `ShareId`，不依赖临时行对象。切换排序、转存/浏览/下载指标、状态筛选或搜索后，已选记录仍然保留。
- 表头复选框表示当前筛选结果：全部选中时为勾选、部分选中时为不确定状态、全部未选时为空。空结果时为空且禁用。部分选中时点击表头会补全选中当前结果；全部选中时点击会清除当前结果。
- `已选 N 条` 统计该账号当前快照中所有已选记录，`共 M 条` 表示当前筛选结果条数。
- 切换账号时清空旧账号选择，避免跨账号导出。同账号刷新后保留选择与新快照 ShareId 的交集；已经消失的 ShareId 立即从选择集合移除，不计入数量且不可导出。

## Excel 导出

- “导出表格”只导出当前账号所有已勾选记录；没有勾选时按钮禁用。
- 导出顺序按当前指标和当前排序规则排列，搜索或状态筛选不会悄悄丢弃已经选中但暂时隐藏的记录。页面编号、区间选取和导出复用同一个全序比较器；主排序键相同时依次以分享时间降序和 `ShareId` 序号比较作为最终稳定 tie-breaker。
- 用户选择保存目录后，生成带本地时间戳且不覆盖现有文件的 `.xlsx`。
- 导出列顺序为：`序号、指标、历史累计、新增、今天、昨天、三个具体日期、链接、标题、状态`。
- 五日窗口统一由 `AccountShareAnalyticsProjector` 按北京时间生成。导出开始时冻结当前五个 `DateOnly`、对应的三个 `MM-dd` 表头以及每条选中记录的完整投影；跨午夜、后台刷新或后续排序变化不得改变正在生成的文件。
- “指标”写入当前选择的 `转存`、`浏览` 或 `下载`。
- 序号写入导出集合中的连续序号，从 1 开始。
- 复用现有文本型流式工作簿契约：序号和统计值写为无千分位的十进制文本，缺失统计值写空文本，新增值保留负号但不添加界面强调用的 `+`；三个日期只作为 `MM-dd` 文本表头。链接写为经过公式注入防护的普通文本而不是活动超链接；状态固定写为 `有效` 或 `失效`。
- 使用现有流式 OpenXML 写入和原子文件发布能力，支持大量记录，不一次性构造完整工作簿内存副本。
- 用户取消目录选择视为正常取消；导出期间禁用重复导出；成功后显示导出条数和安全文件名，失败只显示稳定中文提示，不泄露路径、异常或账号会话数据。

## 组件边界

### 远端解析

`BaiduAccountShareAnalyticsClient` 负责从冻结的远端响应中提取真实标题并过滤占位值。解析规则由合成契约测试固定。

### 页面选择状态

`ShareAnalyticsViewModel` 保存所选 `ShareId` 集合、序号范围、命令状态和选中统计。每次重建可见行时，根据稳定 ID 恢复勾选并重新编号。

行对象只公开显示字段、序号和勾选状态，不执行文件 I/O。

### 导出服务

新增分享数据专用导出适配层，将选中的投影记录转换为工作簿布局和流式行，并必须复用现有 `IReplacementWorkbookFilePublisher` 的 OpenXML 原子发布能力。页面只负责请求目录、调用服务和显示安全结果，不另建第二套文件发布机制。

## 性能与一致性

- 选择集合为哈希集合，单条勾选和恢复为常数级查找。
- 批量命令只遍历当前筛选结果全集；10 万条选择操作不得逐条触发完整 `Rebuild`、完整排序、命令重算或汇总通知。
- 批量选择在后台计算新 HashSet 和新的行选择投影，在 UI 线程至多执行一次 `VisibleItems` 替换、一次选中汇总通知和一次导出命令重算。批量操作期间以 `IsSelectionBusy` 禁止重入；测试通过通知次数验证这一边界，不使用脆弱的固定毫秒门槛。
- 导出开始时冻结账号、指标、排序、五日日期窗口、已选 ID 和完整选中行投影；后台刷新不能改变正在导出的内容。
- 每次导出使用操作代次。切换账号、关闭页面或应用关闭时取消尚未完成的导出；迟到的旧导出完成不得覆盖新账号页面状态。正式目标文件仅在完整写入成功后出现。

## 错误与安全边界

- 分享数据同步、筛选、选择和导出继续是只读远端流程。
- 不导出 CK、Cookie、账号内部标识、本机数据库路径或诊断堆栈。
- 标题和链接作为工作簿文本写入时沿用现有公式注入转义和 Excel 单元格长度限制。
- 单个标题无效时使用安全兜底，不因展示字段问题删除整页统计。

## 测试与验收

- 远端响应 `name: "0"` 且存在有效资源路径时，缓存标题为路径最后一级名称。
- 旧缓存标题为 `0` 时，页面显示稳定分享标识而不是 `0`。
- XAML 不再包含“分享时间”列，列顺序与规格一致，所有表头垂直对齐。
- 当前筛选结果序号从 1 连续编号；排序和筛选后重新编号。
- 单选、表头全选、反选、清空和区间选取行为正确。
- 筛选或切换指标后隐藏选择仍保留；切换账号后清空。
- 10 万条批量选择不会为每行触发完整重建。
- 10 万条批量选择至多产生一次可见行集合替换、一次选中汇总通知和一次导出命令状态重算。
- 无选择时不能导出；取消目录选择不创建文件。
- 导出的 Excel 列名、顺序、文本规范、选中集合、冻结日期窗口和稳定排序正确，通过 OpenXML 验证。
- 导出失败不留下正式半文件，界面显示安全中文状态。
- 相同主排序键仍以分享时间和 `ShareId` 保持稳定编号；同账号刷新保留有效交集并移除过期 ID。
- 空筛选结果禁用表头复选框；部分选中时表头点击补全，全部选中时表头点击清除。
- 工作簿覆盖公式注入、单元格长度限制、文件名碰撞、取消操作与临时文件清理。
- DataGrid 横向滚动条可见，拖到右侧能看到链接、标题和状态。
- 真实窗口验收表头对齐、区间选取、排序高亮、横向滚动和选中导出。
