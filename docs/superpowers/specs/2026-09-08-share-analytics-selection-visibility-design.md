# 分享数据选中行可见性设计

## 目标

修复“分享数据”表格中勾选或选中一行后，文字及操作内容因系统选中前景色与浅色背景冲突而不可见的问题。

## 范围

- 仅修改 `ShareAnalyticsView.xaml` 内分享数据表格的局部样式。
- 选中行使用浅蓝色背景和深色文字。
- 表格失去键盘焦点后，选中内容仍保持相同的清晰可见效果。
- 排序列与选中行重叠时保留浅黄色背景，但仍使用深色文字；其他选中单元格使用浅蓝背景。
- 复选框、打开按钮、横向滚动和现有数据绑定保持不变。
- 不修改全局主题，不影响批量转存等其他表格。

## 验收标准

1. 未选中行显示保持不变。
2. 选中任意行后，序号、统计数值、链接按钮、标题和状态均可读。
3. 切换焦点后，选中行内容仍可读。
4. 结构回归测试能阻止局部选中样式被意外删除。
