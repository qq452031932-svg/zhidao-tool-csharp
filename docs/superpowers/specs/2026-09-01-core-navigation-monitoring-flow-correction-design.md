# 核心导航与转存分享流程纠正设计

## 目标

按照用户提供的 SuperPan 参考界面纠正当前产品结构。账号管理保留在左栏，功能导航改为“首页、链接监控、批量转存、广告插入、文件排除、数据统计、设置中心”。独立分享不再作为主导航；分享能力作为批量转存的可选后续步骤，完成后保存并导出新分享链接与提取码。

## 本期范围

### 可用模块

- **链接监控**：默认首页。支持粘贴/导入、删除、开始、暂停、停止，分组、检查间隔、关键词过滤、保存配置；展示监控链接表和固定高度日志。监控项保存在本机数据库。每轮通过 `ILinkMonitoringProbe` 检查链接并更新“最后检查时间/状态”；生产组合复用已有百度分享预检能力，不另造写操作。导航切换不停止任务，应用关闭会取消并释放定时循环。
- **批量转存**：复用既有导入、账号选择、目标目录、任务执行和结果工作区；默认流程为导入链接 → 转存 → 可选自动分享 → 保存/导出新链接。
- **账号管理**：继续复用既有登录、管理、刷新和账号选择能力。

### 暂缓模块

首页、广告插入、文件排除、数据统计、设置中心在导航中按参考图保留，但本期以明确的“功能建设中”页面承载，不伪造业务结果。后续逐项实现。

### 保留但降级入口

现有独立分享工作区及其后台服务不删除，以避免丢失已完成代码；本期彻底隐藏其 UI 入口，只作为内部代码保留，不影响批量转存中的自动分享。

## 信息架构

窗口保持三栏：

1. 账号管理栏：账号汇总、账号卡、登录/管理入口。
2. 功能导航栏：七个参考图模块，链接监控为默认选中项。
3. 工作台：模块标题、顶部工具栏、主数据表、固定底部日志。

## 视觉规则

- 所有按钮使用同一套扁平圆角模板，不再显示默认 Windows 灰色立体按钮。
- 普通按钮为白底浅边框，主按钮为浅蓝或品牌蓝，禁用状态保持可读。
- 导航未选中项无明显边框，选中项为整块浅蓝背景。
- 输入框、下拉框、按钮统一为 34px 高；面板圆角 6px，浅灰边框。
- 工作台表格为视觉中心；日志固定在底部，每条日志使用独立浅色行。

## 主流程

```text
链接监控发现或用户手工导入链接
  → 选择监控项并执行“转到批量转存”
  → 按原链接、提取码和标题映射到转存导入草稿，按规范化分享 ID 去重
  → 批量转存选择账号与目标目录
  → 执行转存
  → 若勾选“转存完成后自动分享”则分享同一个落盘对象
  → 写入新分享链接与提取码
  → 用户保存或导出结果
```

## 错误处理

- 未实现模块显示清楚的建设中说明，不抛出异常。
- 监控配置无效时禁用开始按钮并给出中文提示；开始只允许一个循环，暂停保留列表与游标，继续从下一轮开始，停止取消当前等待并回到停止状态。
- 监控配置和链接列表使用本机持久化存储；保存失败留在当前页面并写入脱敏日志。
- 监控日志必须复用 `WorkspaceLogEntry` 的 URL、提取码、路径、令牌和账号信息脱敏规则。
- 转存、分享、导出继续复用既有错误隔离、脱敏日志和结果投影。
- 切换模块不得清空正在编辑的转存数据或泄露上一批次的分享结果。

## 验收标准

- 主导航不再出现独立“分享”。
- 主导航七项名称和顺序与参考图一致。
- 默认打开“链接监控”，其按钮、筛选控件、表格和日志均可见且布局接近参考图。
- 链接监控能新增/导入/删除链接，定时执行探测，保存并恢复配置；暂停、继续、停止和关闭取消具有自动化测试。
- 选中的监控链接可以无重复地交给批量转存草稿，原链接、提取码和标题映射正确。
- “批量转存”页面存在“转存完成后自动分享”和结果目录配置；处理结果能显示新分享链接/提取码并可导出。
- 回归测试覆盖转存成功后分享同一落盘对象、分享失败、旧批次隔离和导出失败；只有当前批次已确认的新链接/提取码可导出。
- 按钮不再使用默认 Windows 灰色方框模板。
- 相关单元测试、XAML 结构测试和解决方案构建通过。
