# 分享数据序号列收窄设计

## 目标

把分享数据表格中的“序号”列从 `58px` 收窄到 `44px`，减少无效留白，为右侧统计和标题列腾出空间。

## 范围

- 只修改 DataGrid 的“序号”显示列宽度。
- 保持现有对齐不变：表头居中，行序号右对齐。
- “选择”列以及工具栏中的“从/到”范围输入框宽度保持不变。
- 不改变连续编号、筛选、排序、选择或导出行为。

## 标题说明

当前标题显示为数字，是因为旧缓存中的标题为占位值 `0`，页面使用稳定分享 ID 兜底，避免继续显示错误的 `0`。本轮不触发全盘同步，也不改变缓存策略；下一次用户手动刷新或 23 小时到期自动同步后，新标题解析器会从 `typicalPath`、`name` 中写入真实标题。

## 验收

- XAML 结构测试断言序号列宽度为 `44`。
- 分享数据 ViewModel/结构测试继续通过。
- Release 构建通过。
- 真实窗口中序号列明显收窄，编号仍完整可见。
