# 批量转存结果可见性设计

## 目标

批量转存创建后自动打开“处理结果”，运行期间自动刷新；应用重启后自动加载最近批次并显示结果。用户选中一条已生成分享的结果后，可以一键复制分享链接和提取码，现有“另存结果表格”继续负责批量导出。

## 设计

- `TransferWorkspaceViewModel` 暴露当前数据页索引。导入新草稿时回到“待处理链接”；结果 ViewModel 绑定任一批次时切到“处理结果”。
- `WorkspaceRunPanelViewModel` 复用现有批次历史源，每隔数秒刷新当前活动批次的状态和结果；批次进入终态后停止自动刷新，关闭工作台时取消循环。
- `JobResultsViewModel` 增加选中行复制命令，仅当该行同时有新分享链接和提取码时可用。剪贴板通过小型接口注入，便于测试并确保 UI 线程调用。
- 复制文本统一为两行：分享链接、提取码。状态栏只显示“已复制”，不回显敏感内容。

## 错误处理

- 自动刷新失败只保留友好提示，下个周期继续尝试，不影响后台转存。
- 剪贴板不可用时显示“复制失败，请稍后重试”，不泄漏链接或提取码。
- 旧批次的迟到刷新不得覆盖用户后来选择的新批次。

## 验证

- ViewModel 测试覆盖自动切页、活动批次刷新、终态停止、关闭取消和复制成功/失败。
- XAML 测试确认结果 Tab 绑定、复制按钮和既有导出按钮同时存在。
- 运行聚焦测试、解决方案构建和真实数据库界面检查。
