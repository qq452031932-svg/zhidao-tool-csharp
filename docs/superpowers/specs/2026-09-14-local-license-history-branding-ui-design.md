# 知道综合工具：本地授权、历史清理与品牌界面调整设计

## 背景与目标

本次仅调整 Windows 本地客户端，不部署服务器、不修改授权服务端，也不对百度网盘执行删除操作。

目标包括：

1. 在主界面明确显示当前卡密的套餐与到期时间。
2. 为转存和分享工作区提供真正持久的“清空历史”能力。
3. 改善卡密激活窗口的视觉层级、说明文字与操作反馈。
4. 将面向用户的软件名称统一改为“知道综合工具”。

## 安全边界

“清空历史”仅删除本地数据库中的终态任务及其关联本地记录，不调用百度网盘的删除、取消分享或文件操作接口。

- 百度网盘中已经转存的文件保持不变。
- 百度网盘中已经生成的分享链接保持有效。
- 本地保存的分享链接副本可随对应历史任务一并删除；删除后软件不再展示该副本。
- 百度账号、登录会话、账号容量、软件设置和授权凭据不得删除。
- 运行中、等待中、暂停中或仍需处理的任务不得删除。
- 删除前必须二次确认，并明确显示“仅删除本地记录，不影响百度网盘文件和分享链接”。

## 方案选择

采用“删除本地终态历史”的方案，不采用仅清空界面集合或删除全部数据库任务的方案。

- 仅清空界面集合会在重启后重新加载，无法满足持久清空需求。
- 删除全部任务可能破坏仍在执行或可恢复的任务。
- 只删除终态任务可满足用户清理界面的目的，同时保护未完成任务。

## 授权信息显示

主窗口产品标题区域右侧新增紧凑的授权状态信息，和“当前模块”区域保持同一视觉体系。

显示内容：

- 已激活时：套餐名称与“有效期至 yyyy-MM-dd HH:mm”。当前协议只支持有明确到期时间的时长卡，不推断或显示“永久有效”。
- 未激活或无法读取时：显示“未激活”或安全的不可用提示，不暴露卡密正文、机器码、签名载荷等敏感信息。

数据来源必须是授权门禁在本次启动验证或本次激活过程中**实际接受**的已验证签名声明，而不是再次遍历本地凭据并自行挑选。授权成功路径把安全摘要（套餐名、到期时间）发布到运行时授权状态；在线验证、离线缓存验证和新卡激活都走同一发布路径。后续获准声明替换先前摘要，拒绝或失效时不得继续展示旧摘要。不得为了显示有效期而新增不必要的远程请求。激活成功后应立即刷新主界面的授权信息。

## 历史清理交互

### 转存工作区

- “处理结果”页提供“清空转存历史”按钮。
- “运行日志”页提供“清空日志”按钮。
- “清空转存历史”永久删除本地所有终态转存批次及其级联关联结果；非终态批次保留。
- 删除成功后刷新最近任务、当前选择、统计和结果表格；若没有可显示任务，则进入空状态。
- “清空日志”只清除当前进程内存中的最近 100 条界面日志，不操作持久任务。

### 分享工作区

- “分享结果”区域提供“清空分享历史”按钮。
- “运行日志”区域提供“清空日志”按钮。
- “清空分享历史”永久删除本地所有终态独立分享批次及其关联操作和本地结果；非终态批次保留。
- 删除成功后重新加载第一页历史；若没有历史，则清空选择和结果表格并显示空状态。
- “清空日志”只清除当前进程内存中的最近 100 条界面日志。

### 确认、并发与失败处理

- 历史删除按钮在工作区繁忙或存在冲突操作时禁用。
- 确认对话框说明本地删除范围和百度网盘不受影响，并给出可删除的终态任务数量。
- 数据库删除在事务中完成；失败时回滚并保留原界面状态，展示可理解的错误提示。
- 确认框中的数量只用于提示；事务开始后必须重新按终态条件筛选，避免确认期间任务状态变化导致误删。
- 若没有可删除的终态任务，不弹无意义确认框，直接提示“没有可清理的历史任务”。
- 清理动作不得绕过现有账号与任务安全边界，也不得删除处于活动状态的数据。
- 已经导出的 Excel、CSV 或其他用户文件不属于数据库历史，清理时不得删除。

## 卡密激活窗口

激活窗口改为清晰的卡片式结构，沿用主程序青绿色品牌色，不引入图片生成资产。

- 顶部显示“知道综合工具”和副标题“软件授权”。
- 主体提供“请输入卡密”的字段标签、示例占位说明以及简短提示：“卡密将绑定当前电脑，请确认后激活”。
- 输入框增加合适高度、内边距和清晰焦点状态；不回显或记录敏感信息到日志。
- 主操作按钮改为品牌色“立即激活”，次操作为“暂不激活”。
- 激活过程中禁用重复提交并显示“正在激活…”。
- 错误提示使用明确但不泄露内部信息的文案；成功后保持现有自动关闭并进入应用的行为。
- 支持键盘默认操作、取消操作和现有自动化辅助名称。

## 品牌名称

所有面向用户的产品名统一为“知道综合工具”，包括：

- Windows 主窗口标题栏与产品标题。
- 卡密激活窗口标题与正文标题。
- 消息框标题。
- OTA 本地验收版标题，格式为“知道综合工具 · OTA 本地验收版”。
- 默认结果导出显示名称调整为“知道综合工具结果”。

“百度网盘”仍可出现在功能描述、账号说明和业务字段中，因为它描述的是所连接的平台，不属于旧产品名残留。主界面副标题改为“百度网盘批量管理工作台”。

## 数据与实现边界

- 在应用层定义明确的终态历史清理服务或存储接口，基础设施层实现 SQLite 事务删除。
- 转存终态按现有批次终态集合处理：`Completed`、`CompletedWithShortfall`、`Cancelled`。
- 独立分享终态按现有分享批次终态集合处理：`Completed`、`CompletedWithFailures`、`Cancelled`。
- 转存历史删除必须先构造事务内目标集合，并显式处理非级联引用：删除 `LocalResultExports` 中 `OwnerKind='TransferBatch'` 的目标记录；按 `Transfer` 与 `TransferShare` 所属操作删除 `WebAutomationAttempts` 及其目录变更、来源项、远端项、映射和接受证据等子表；删除目标 `ExecutionLogs`、分享操作、转存操作、账号分配、资源和批次。删除 `BatchJobs` 前，将 `ImportSessions.CreatedBatchJobId` 和 `ImportSessions.AppendToBatchJobId` 中指向目标批次的引用置空；导入会话及其原始导入行保留，避免影响可能仍被其他批次引用的数据。
- 独立分享历史删除必须显式删除 `LocalResultExports` 中 `OwnerKind='StandaloneShareBatch'` 的目标记录，并按 `StandaloneShare` 所属操作删除 `WebAutomationAttempts` 及其子表；随后删除目标 `StandaloneShareOperations` 和 `StandaloneShareBatches`，让其有真实外键的远端项、基线和结果表按现有级联规则清理。
- 删除顺序应复用或抽取现有账号终态历史清理中已经验证过的自动化证据清理逻辑，避免维护两套不一致的表闭包；事务完成前执行引用完整性与目标残留检查。
- 实现必须通过测试证明账号、登录会话、授权凭据、应用设置、导入原始数据、非终态任务以及磁盘上的导出文件未被删除。
- 界面日志缓冲区增加显式清空能力，只影响内存集合。
- 授权摘要模型只接收授权门禁实际获准声明发布的套餐名和到期时间，并以本地时间格式化；不得按凭据顺序、最晚到期时间或套餐名称猜测当前卡密。

## 测试与验收

至少覆盖：

1. 品牌文字在主窗口、激活窗口、消息框入口和导出名称中统一。
2. 授权摘要正确显示当前实际获准卡密的套餐与到期时间，并覆盖未激活、多凭据、缓存获准、在线获准和获准声明切换场景。
3. 激活窗口结构、命令状态和激活中反馈正确。
4. 清理转存历史只删除终态批次及关联本地数据，保留非终态批次、账号和设置。
5. 清理分享历史只删除终态批次及关联本地数据，保留非终态批次、账号和设置。
6. 用户取消确认时不修改数据库。
7. 删除失败时事务回滚，界面不伪装成功。
8. 清空运行日志后日志集合为空，且不影响数据库任务。
9. 重启或重新初始化后，被删除的终态历史不再加载，保留的非终态任务仍可加载。
10. 完成相关单元测试、结构测试与应用构建，不进行服务器部署。
11. 历史清理后通过外键检查和残留查询；非级联自动化证据与本地导出队列记录不得成为孤儿。

## 非目标

- 不修改授权管理后台和服务器部署。
- 不重新设计主工作区的整体布局。
- 不删除百度网盘文件，不取消百度网盘分享。
- 不实现数据库全量重置或账号一键清空。
- 不新增付费代码签名或安装包签名方案。
