Managed Browser Helper — third-party notices and build policy
=============================================================

This source notice is the deterministic inventory header. The packaging script appends
the complete license text shipped by CPython and every locked wheel to the packaged copy
of this file. A package without this notice is rejected by the runtime verifier.

Distribution policy
-------------------

This helper may be built and redistributed commercially. Every bundled component carries
a permissive license (PSF-2.0, MPL-2.0, Apache-2.0, MIT or BSD-3-Clause) that allows
binary redistribution as long as its notice travels with the build, which this file
provides. The earlier restriction to DistributionMode=PersonalNonCommercial existed
because the third-party browser driver's custom license withheld commercial
distribution. That driver has been removed and replaced by this helper's own DevTools
Protocol client (cdp_client.py), which needs nothing beyond the packages pinned below.

certifi is covered by MPL-2.0 and is redistributed unmodified, so only the notice
obligation applies; the complete MPL-2.0 text is packaged alongside this file.
