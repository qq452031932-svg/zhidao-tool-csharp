# Locked license inputs

`MPL-2.0.txt` is the complete Mozilla Public License 2.0 text reviewed against
Mozilla's canonical plain-text publication:

https://www.mozilla.org/media/MPL/2.0/index.f75d2927d3c1.txt

The packaging script accepts the source only when its LF-normalized file bytes have SHA-256:

`3f3d9e0024b1921b067d6f7f88deb4a60cbe7a78e76c64e3f1d7fc3b779b9d04`

The source is intentionally repository-owned and hash locked. A package build never downloads
license text or substitutes package metadata URLs at build time.
